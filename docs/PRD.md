# KONEKT public website product contract

## Outcome

Help a visitor understand what KONEKT does in less than one page section, then give them an honest next action:

1. Explore how service discovery works.
2. Understand how Kreyòl access is described.
3. Learn how to add or claim a provider profile.
4. Reach support or accurate platform-release information.

## Audiences

- Haitian and Haitian Creole-speaking community members seeking services
- Family members helping relatives find care or professional support
- Community organizations and service navigators
- Providers and businesses that want to maintain an accurate public profile

## Positioning

KONEKT is a focused service directory, not a social network or generic global marketplace. The website centers the product's strongest distinction: it describes whether Kreyòl is offered directly, through staff, or through an interpreter.

## Requirements

- English and Haitian Creole controls must update the primary public experience.
- Community discovery must remain account-free.
- Healthcare-specific language must not leak into unrelated categories.
- Product previews must be clearly illustrative.
- Every visible CTA must navigate, filter, switch language, open support, or report truthful platform status.
- App-store badges and links must not appear until official listing URLs are configured.
- Public copy must not invent metrics, testimonials, ratings, certifications, moderation SLAs, product capabilities, or data collection.
- The website must work at 390, 768, 1024, and 1440 CSS pixels without horizontal overflow.
- Reduced-motion, keyboard focus, semantic headings, accessible names, and 44-pixel interactive targets are required.

## Non-goals

- Public directory API integration
- Provider authentication or submission
- Admin moderation
- Service-role access
- Newsletter collection
- Behavioral analytics before a documented privacy decision
- Payments, tickets, messaging, community accounts, or social feeds

## Definition of done

The design reference is implemented, multi-viewport captures are retained, the primary interactions and public routes pass browser verification, the console is clean, `npm run check` passes, and `design-qa.md` ends with `final result: passed`.
